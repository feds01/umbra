# umbra

> Classify every database column for personal data, and read only what each class allows.

An umbra is the dark centre of a shadow. umbra keeps your personal data in it.

Each column gets a class in the model that stores it. umbra checks the classes against
the schema your database really has, and renders Postgres and BigQuery views that show
each column the way its class allows: the value, a masked form of it, or nothing.

A column nobody has classified fails the check, so new personal data can't slip into
the views unseen.

## Installation

```sh
go get github.com/feds01/umbra
```

Go 1.24 or later. Nothing outside the standard library.

## A quick look

Tag the model:

```go
type Contact struct {
	ID    string `pii:"allow"`
	OrgID string `pii:"allow"`
	Name  string `pii:"deny=person"`
	Email string `pii:"generalise=domain,pseudonymise"`
}
```

Register it, and write the catalog that reviewers read:

```go
policy := umbra.Policy{
	Reasons: []umbra.Reason{"person", "credential"},
	Maskers: []umbra.Masker{
		{Term: "generalise=domain", Suffix: "domain", Kinds: umbra.Text},
		{Term: "pseudonymise", Suffix: "pseudonym", Kinds: umbra.Text, Reads: []string{"org_id"}},
	},
}

registry := umbra.NewRegistry(policy, nil)
umbra.Model[Contact](registry.Dataset("postgres"), "contacts")

catalog, err := registry.Catalog() // every bad tag at once
err = catalog.WriteDir("catalog")  // catalog/postgres/contacts.pii
```

```text
# Code generated by umbra. DO NOT EDIT.
id allow
org_id allow
name deny=person
email generalise=domain,pseudonymise
```

Render the masked views:

```go
views := postgres.Views{Schema: "masked", Source: "public", Role: "analyst", Masks: map[string]postgres.Expr{
	"generalise=domain": postgres.Extract(umbra.EmailPattern),
	"pseudonymise":      postgres.HMAC("org_id", "SELECT key FROM private.pseudonym_key"),
}}
sql, err := views.SQL(catalog, "postgres") // masked.contacts: id, org_id, email_domain, email_pseudonym
```

In CI, `catalog.Check("postgres", schema)` with `postgres.ReadSchema` fails on any
column nobody classified. At runtime, `umbra.Load` reads the catalog without importing
a model.
